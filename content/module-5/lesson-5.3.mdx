# Phase 3: API, Serving & Putting It All Together

A model that lives in a notebook is a prototype. A model behind an API is a product. In this
final phase, you will serialize your trained model, wrap it in a FastAPI backend, add input
validation, write a test script, and document the entire project. By the end, someone else
should be able to clone your repository and get predictions from your model with a single
HTTP request.

<WhyThisMatters>
Most ML job postings include "deploy models to production" as a requirement. Building an API
around your model demonstrates that you understand the full lifecycle — not just the Jupyter
notebook part. This phase is what turns a school project into a portfolio piece.
</WhyThisMatters>

## Step 1: Model Serialization

You need to save your model in a format that can be loaded without the training code. You
already saved a checkpoint in Phase 2. Now make sure the serialization is self-contained.

### PyTorch Model

```python
import torch
import torch.nn as nn

# Recreate the model class (this must be importable by the serving code)
class TabularNet(nn.Module):
    def __init__(self, input_dim, hidden_dims, output_dim, dropout_rate=0.3):
        super().__init__()

        layers = []
        prev_dim = input_dim

        for h_dim in hidden_dims:
            layers.append(nn.Linear(prev_dim, h_dim))
            layers.append(nn.BatchNorm1d(h_dim))
            layers.append(nn.ReLU())
            layers.append(nn.Dropout(dropout_rate))
            prev_dim = h_dim

        layers.append(nn.Linear(prev_dim, output_dim))
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        return self.network(x)
```

### Loading the Checkpoint

```python
import joblib

def load_model(checkpoint_path="models/final_model.pt"):
    checkpoint = torch.load(checkpoint_path, map_location="cpu")

    model = TabularNet(
        input_dim=checkpoint["input_dim"],
        hidden_dims=checkpoint["hidden_dims"],
        output_dim=checkpoint["output_dim"],
        dropout_rate=checkpoint["dropout_rate"],
    )
    model.load_state_dict(checkpoint["model_state_dict"])
    model.eval()
    return model

def load_preprocessors():
    scaler = joblib.load("data/processed/scaler.joblib")
    imputer = joblib.load("data/processed/num_imputer.joblib")
    return scaler, imputer
```

<CommonMistake>
A common deployment bug is forgetting to call `model.eval()` after loading. In eval mode,
dropout is disabled and batch normalization uses running statistics instead of batch statistics.
If you serve predictions with the model in training mode, your results will be noisy and
non-deterministic.
</CommonMistake>

## Step 2: Build the Prediction Pipeline

Before building the API, write a pure Python function that takes raw input and returns a
prediction. This function encapsulates all preprocessing and inference logic.

```python
import numpy as np
import pandas as pd

def predict(raw_input: dict, model, scaler, imputer, feature_names: list) -> dict:
    """
    Takes a raw input dictionary, preprocesses it, runs inference,
    and returns a prediction dictionary.

    Parameters
    ----------
    raw_input : dict
        Feature name -> value mapping. Example: {"age": 45, "cholesterol": 200}
    model : TabularNet
        Loaded PyTorch model in eval mode.
    scaler : StandardScaler
        Fitted scaler from Phase 1.
    imputer : SimpleImputer
        Fitted imputer from Phase 1.
    feature_names : list
        Ordered list of feature names the model expects.

    Returns
    -------
    dict
        {"prediction": int_or_float, "probability": float (for classification)}
    """
    # Create DataFrame with correct column order
    df = pd.DataFrame([raw_input])

    # Ensure all expected columns are present
    for col in feature_names:
        if col not in df.columns:
            df[col] = np.nan

    df = df[feature_names]

    # Apply preprocessing
    df_imputed = pd.DataFrame(imputer.transform(df), columns=feature_names)
    df_scaled = pd.DataFrame(scaler.transform(df_imputed), columns=feature_names)

    # Convert to tensor and predict
    input_tensor = torch.tensor(df_scaled.values, dtype=torch.float32)

    with torch.no_grad():
        logits = model(input_tensor)
        probability = torch.sigmoid(logits).item()
        prediction = int(probability > 0.5)

    return {
        "prediction": prediction,
        "probability": round(probability, 4),
    }
```

### Create the Application

Create a file called `app.py` in your project root.

```python
# app.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
import pandas as pd
import torch

from model import TabularNet, load_model, load_preprocessors

# --- Application Setup ---

app = FastAPI(
    title="ML Capstone Prediction API",
    description="Serves predictions from a trained classification/regression model.",
    version="1.0.0",
)

# Load model and preprocessors at startup
model = None
scaler = None
imputer = None
feature_names = None


@app.on_event("startup")
def startup_event():
    global model, scaler, imputer, feature_names
    model = load_model("models/final_model.pt")
    scaler, imputer = load_preprocessors()
    feature_names = list(pd.read_csv("data/processed/X_train.csv").columns)
    print(f"Model loaded. Expecting {len(feature_names)} features.")


# --- Request / Response Schemas ---

class PredictionRequest(BaseModel):
    """
    Input features for prediction. Adjust field names and types
    to match your dataset.
    """
    # Example fields for Heart Disease dataset:
    age: float = Field(..., ge=0, le=120, description="Age in years")
    sex: int = Field(..., ge=0, le=1, description="0 = female, 1 = male")
    cp: int = Field(..., ge=0, le=3, description="Chest pain type (0-3)")
    trestbps: float = Field(..., ge=50, le=300, description="Resting blood pressure (mm Hg)")
    chol: float = Field(..., ge=50, le=600, description="Serum cholesterol (mg/dl)")
    fbs: int = Field(..., ge=0, le=1, description="Fasting blood sugar > 120 mg/dl")
    restecg: int = Field(..., ge=0, le=2, description="Resting ECG results (0-2)")
    thalach: float = Field(..., ge=50, le=250, description="Maximum heart rate achieved")
    exang: int = Field(..., ge=0, le=1, description="Exercise induced angina")
    oldpeak: float = Field(..., ge=0, le=10, description="ST depression induced by exercise")
    slope: int = Field(..., ge=0, le=2, description="Slope of peak exercise ST segment")
    ca: int = Field(..., ge=0, le=4, description="Number of major vessels colored by fluoroscopy")
    thal: int = Field(..., ge=0, le=3, description="Thalassemia type (0-3)")

    class Config:
        json_schema_extra = {
            "example": {
                "age": 55, "sex": 1, "cp": 2, "trestbps": 140, "chol": 250,
                "fbs": 0, "restecg": 1, "thalach": 150, "exang": 0,
                "oldpeak": 1.5, "slope": 1, "ca": 0, "thal": 2,
            }
        }


class PredictionResponse(BaseModel):
    prediction: int = Field(..., description="Predicted class label")
    probability: float = Field(..., description="Predicted probability for positive class")
    model_version: str = Field(default="1.0.0")


# --- Endpoints ---

@app.get("/health")
def health_check():
    """Returns server status and whether the model is loaded."""
    return {
        "status": "healthy",
        "model_loaded": model is not None,
    }


@app.post("/predict", response_model=PredictionResponse)
def make_prediction(request: PredictionRequest):
    """
    Accepts input features and returns a model prediction.

    The input is validated against the schema. Missing or out-of-range
    values will return a 422 error with details.
    """
    try:
        raw_input = request.model_dump()

        result = predict_from_raw(raw_input)

        return PredictionResponse(
            prediction=result["prediction"],
            probability=result["probability"],
        )
    except Exception as e:
        raise HTTPException(status_code=500, detail=f"Prediction failed: {str(e)}")


def predict_from_raw(raw_input: dict) -> dict:
    """Internal prediction function using the globally loaded model."""
    import numpy as np

    df = pd.DataFrame([raw_input])

    for col in feature_names:
        if col not in df.columns:
            df[col] = np.nan

    df = df[feature_names]
    df_imputed = pd.DataFrame(imputer.transform(df), columns=feature_names)
    df_scaled = pd.DataFrame(scaler.transform(df_imputed), columns=feature_names)

    input_tensor = torch.tensor(df_scaled.values, dtype=torch.float32)

    with torch.no_grad():
        logits = model(input_tensor)
        probability = torch.sigmoid(logits).item()
        prediction = int(probability > 0.5)

    return {"prediction": prediction, "probability": round(probability, 4)}
```

## Step 4: Test the API

Write a test script that sends requests to your running API and verifies the responses.

```python
# test_api.py
import requests
import json

BASE_URL = "http://localhost:8000"


def test_health():
    response = requests.get(f"{BASE_URL}/health")
    assert response.status_code == 200
    data = response.json()
    assert data["status"] == "healthy"
    assert data["model_loaded"] is True
    print("PASS: Health check")


def test_prediction_valid_input():
    payload = {
        "age": 55, "sex": 1, "cp": 2, "trestbps": 140, "chol": 250,
        "fbs": 0, "restecg": 1, "thalach": 150, "exang": 0,
        "oldpeak": 1.5, "slope": 1, "ca": 0, "thal": 2,
    }
    response = requests.post(f"{BASE_URL}/predict", json=payload)
    assert response.status_code == 200
    data = response.json()
    assert "prediction" in data
    assert "probability" in data
    assert data["prediction"] in [0, 1]
    assert 0.0 <= data["probability"] <= 1.0
    print(f"PASS: Valid prediction -> {data}")


def test_prediction_invalid_input():
    # Missing required field
    payload = {"age": 55}
    response = requests.post(f"{BASE_URL}/predict", json=payload)
    assert response.status_code == 422
    print("PASS: Invalid input rejected with 422")


def test_prediction_out_of_range():
    payload = {
        "age": -5, "sex": 1, "cp": 2, "trestbps": 140, "chol": 250,
        "fbs": 0, "restecg": 1, "thalach": 150, "exang": 0,
        "oldpeak": 1.5, "slope": 1, "ca": 0, "thal": 2,
    }
    response = requests.post(f"{BASE_URL}/predict", json=payload)
    assert response.status_code == 422
    print("PASS: Out-of-range value rejected with 422")


def test_batch_predictions():
    """Send multiple predictions and check consistency."""
    payload = {
        "age": 55, "sex": 1, "cp": 2, "trestbps": 140, "chol": 250,
        "fbs": 0, "restecg": 1, "thalach": 150, "exang": 0,
        "oldpeak": 1.5, "slope": 1, "ca": 0, "thal": 2,
    }

    results = []
    for _ in range(5):
        response = requests.post(f"{BASE_URL}/predict", json=payload)
        results.append(response.json()["probability"])

    # Same input should give same output (model is in eval mode)
    assert len(set(results)) == 1, f"Non-deterministic results: {results}"
    print("PASS: Deterministic predictions confirmed")


if __name__ == "__main__":
    test_health()
    test_prediction_valid_input()
    test_prediction_invalid_input()
    test_prediction_out_of_range()
    test_batch_predictions()
    print("\nAll tests passed.")
```

Run the tests:

```bash
# Terminal 1: Start the server
uvicorn app:app --host 0.0.0.0 --port 8000

# Terminal 2: Run tests
python test_api.py
```

<CommonMistake>
Do not only test the happy path. Production APIs receive malformed JSON, missing fields,
wrong types, and extreme values. Your test script should verify that bad inputs are rejected
gracefully with proper HTTP status codes (422 for validation errors), not that they cause a
500 server crash.
</CommonMistake>

## Step 5: Input Validation Deep Dive

Pydantic handles most validation through field constraints, but you may need custom validators
for complex rules.

```python
from pydantic import BaseModel, Field, model_validator

class PredictionRequest(BaseModel):
    age: float = Field(..., ge=0, le=120)
    systolic_bp: float = Field(..., ge=50, le=300)
    diastolic_bp: float = Field(..., ge=30, le=200)

    @model_validator(mode="after")
    def check_blood_pressure(self):
        if self.systolic_bp <= self.diastolic_bp:
            raise ValueError(
                f"Systolic BP ({self.systolic_bp}) must be greater than "
                f"diastolic BP ({self.diastolic_bp})"
            )
        return self
```

You can also add type coercion for robust handling of string-encoded numbers:

```python
from pydantic import field_validator

class PredictionRequest(BaseModel):
    age: float

    @field_validator("age", mode="before")
    @classmethod
    def coerce_age(cls, v):
        if isinstance(v, str):
            try:
                return float(v)
            except ValueError:
                raise ValueError(f"Cannot convert '{v}' to a number")
        return v
```
