# Unsupervised Learning: Clustering & Dimensionality Reduction

Every algorithm so far has relied on labeled data: we told the model the correct answer during training and measured how well it learned. But what if we have no labels? What if we simply have a large collection of data points and want to find patterns, groups, or a simpler representation?

This is the domain of **unsupervised learning**. In this lesson, we focus on the two most important families: clustering (grouping similar data) and dimensionality reduction (compressing data while preserving structure).

<WhyThisMatters>
Labels are expensive. Hiring domain experts to annotate thousands of medical images or customer profiles costs time and money. Unsupervised learning lets you extract value from raw, unlabeled data — segmenting customers, detecting anomalies, compressing features before supervised learning, and generating visualizations of complex high-dimensional data.
</WhyThisMatters>

## K-Means Clustering

K-means is the simplest and most widely used clustering algorithm. It partitions $m$ data points into $K$ clusters by minimizing the within-cluster sum of squared distances.

### The Algorithm

1. **Initialize** $K$ centroids randomly (or using a smarter strategy).
2. **Assign** each data point to the nearest centroid.
3. **Update** each centroid to be the mean of its assigned points.
4. **Repeat** steps 2-3 until assignments stop changing (convergence).

<MathNote>
K-means minimizes the **inertia** (within-cluster sum of squares):

$$J = \sum_{k=1}^{K} \sum_{\mathbf{x}^{(i)} \in C_k} \|\mathbf{x}^{(i)} - \boldsymbol{\mu}_k\|^2$$

where $C_k$ is the set of points assigned to cluster $k$, and $\boldsymbol{\mu}_k$ is the centroid of cluster $k$.

This objective is non-convex — K-means can converge to local minima. That is why we run it multiple times with different initializations and keep the best result.
</MathNote>

### K-Means from Scratch

```python
import numpy as np
import matplotlib.pyplot as plt

def kmeans(X, K, max_iters=100, random_state=42):
    """Simple K-means implementation."""
    rng = np.random.RandomState(random_state)
    m, n = X.shape

    # Step 1: Initialize centroids by picking K random data points
    indices = rng.choice(m, K, replace=False)
    centroids = X[indices].copy()

    for iteration in range(max_iters):
        # Step 2: Assign each point to the nearest centroid
        distances = np.linalg.norm(X[:, np.newaxis] - centroids, axis=2)  # (m, K)
        labels = np.argmin(distances, axis=1)

        # Step 3: Recompute centroids
        new_centroids = np.array([
            X[labels == k].mean(axis=0) if np.sum(labels == k) > 0 else centroids[k]
            for k in range(K)
        ])

        # Check convergence
        if np.allclose(centroids, new_centroids):
            print(f"Converged after {iteration + 1} iterations")
            break
        centroids = new_centroids

    return labels, centroids

# Generate synthetic clustered data
from sklearn.datasets import make_blobs
X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42)

# Run our implementation
labels, centroids = kmeans(X, K=4)

# Visualize
plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap="viridis", s=30, alpha=0.7)
plt.scatter(centroids[:, 0], centroids[:, 1], c="red", marker="X", s=200,
            edgecolors="black", linewidths=2, label="Centroids")
plt.title("K-Means Clustering (from scratch)")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### K-Means with Scikit-Learn

```python
from sklearn.cluster import KMeans

kmeans_model = KMeans(n_clusters=4, n_init=10, random_state=42)
kmeans_model.fit(X)

print(f"Cluster labels (first 10): {kmeans_model.labels_[:10]}")
print(f"Centroids shape: {kmeans_model.cluster_centers_.shape}")
print(f"Inertia: {kmeans_model.inertia_:.2f}")

# Predict cluster for new points
new_points = np.array([[0, 0], [5, 5]])
print(f"New point assignments: {kmeans_model.predict(new_points)}")
```

## Choosing K: The Elbow Method and Silhouette Score

K-means requires you to specify $K$ in advance. How do you choose the right number of clusters?

### The Elbow Method

Plot inertia vs. $K$. The "elbow" — where the rate of decrease sharply changes — suggests a good $K$.

```python
inertias = []
K_range = range(1, 11)

for k in K_range:
    model = KMeans(n_clusters=k, n_init=10, random_state=42)
    model.fit(X)
    inertias.append(model.inertia_)

plt.figure(figsize=(8, 5))
plt.plot(K_range, inertias, "o-", linewidth=2)
plt.xlabel("Number of Clusters (K)")
plt.ylabel("Inertia (Within-Cluster Sum of Squares)")
plt.title("Elbow Method for Choosing K")
plt.grid(True, alpha=0.3)
plt.xticks(K_range)
plt.show()
```

### The Silhouette Score

The silhouette score measures how similar each point is to its own cluster compared to other clusters. For each point $i$:

$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

where $a(i)$ is the average distance to other points in the same cluster, and $b(i)$ is the average distance to points in the nearest different cluster.

- $s(i) \approx 1$: point is well-matched to its cluster
- $s(i) \approx 0$: point is on the border between two clusters
- $s(i) \approx -1$: point is likely in the wrong cluster

```python
from sklearn.metrics import silhouette_score, silhouette_samples

silhouette_scores = []
for k in range(2, 11):
    model = KMeans(n_clusters=k, n_init=10, random_state=42)
    labels = model.fit_predict(X)
    score = silhouette_score(X, labels)
    silhouette_scores.append(score)
    print(f"K={k}: Silhouette Score = {score:.3f}")

plt.figure(figsize=(8, 5))
plt.plot(range(2, 11), silhouette_scores, "o-", linewidth=2)
plt.xlabel("Number of Clusters (K)")
plt.ylabel("Average Silhouette Score")
plt.title("Silhouette Score vs. K")
plt.grid(True, alpha=0.3)
plt.xticks(range(2, 11))
plt.show()
```

<CommonMistake>
K-means assumes clusters are roughly spherical and equally sized. It can fail badly on elongated clusters, clusters of very different sizes, or non-convex shapes. If your data has such structure, consider DBSCAN or Gaussian Mixture Models instead. Always visualize your clusters (using PCA if needed) to check whether the result makes sense.
</CommonMistake>

## Limitations of K-Means

```python
from sklearn.datasets import make_moons, make_circles

fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# K-means works well on blobs
X_blobs, _ = make_blobs(n_samples=300, centers=3, cluster_std=0.8, random_state=42)
labels_blobs = KMeans(n_clusters=3, n_init=10, random_state=42).fit_predict(X_blobs)
axes[0].scatter(X_blobs[:, 0], X_blobs[:, 1], c=labels_blobs, cmap="viridis", s=20)
axes[0].set_title("K-Means on Blobs (Works Well)")

# K-means fails on moons
X_moons, _ = make_moons(n_samples=300, noise=0.1, random_state=42)
labels_moons = KMeans(n_clusters=2, n_init=10, random_state=42).fit_predict(X_moons)
axes[1].scatter(X_moons[:, 0], X_moons[:, 1], c=labels_moons, cmap="viridis", s=20)
axes[1].set_title("K-Means on Moons (Fails)")

# K-means fails on concentric circles
X_circles, _ = make_circles(n_samples=300, noise=0.05, factor=0.5, random_state=42)
labels_circles = KMeans(n_clusters=2, n_init=10, random_state=42).fit_predict(X_circles)
axes[2].scatter(X_circles[:, 0], X_circles[:, 1], c=labels_circles, cmap="viridis", s=20)
axes[2].set_title("K-Means on Circles (Fails)")

plt.tight_layout()
plt.show()
```

## Principal Component Analysis (PCA)

PCA is the most widely used dimensionality reduction technique. It finds new axes (principal components) along which the data has the most variance, then projects the data onto fewer dimensions while preserving as much information as possible.

### The Intuition

Imagine a cloud of 3D data points that is shaped like a thin disk. Most of the variation lies along two directions (the plane of the disk), and very little along the third (the thickness). PCA identifies these directions and projects the data onto the 2D plane, losing almost no information.

### The Math

<MathNote>
PCA connects directly to the linear algebra from Module 1:

1. **Center the data**: subtract the mean from each feature.
2. **Compute the covariance matrix**: $\Sigma = \frac{1}{m-1} X_c^T X_c$ where $X_c$ is the centered data.
3. **Find eigenvalues and eigenvectors** of $\Sigma$. The eigenvectors are the principal component directions; the eigenvalues indicate the variance captured by each component.
4. **Project**: multiply the centered data by the top $k$ eigenvectors to get the $k$-dimensional representation.

The first principal component $\mathbf{v}_1$ is the direction that maximizes variance:

$$\mathbf{v}_1 = \arg\max_{\|\mathbf{v}\|=1} \text{Var}(X_c \mathbf{v}) = \arg\max_{\|\mathbf{v}\|=1} \mathbf{v}^T \Sigma \mathbf{v}$$

This is solved by the eigenvector corresponding to the largest eigenvalue of $\Sigma$.
</MathNote>

### PCA from Scratch

```python
import numpy as np

def pca_from_scratch(X, n_components):
    """PCA implementation using eigendecomposition."""
    # Step 1: Center the data
    mean = X.mean(axis=0)
    X_centered = X - mean

    # Step 2: Covariance matrix
    cov_matrix = np.cov(X_centered, rowvar=False)

    # Step 3: Eigenvalues and eigenvectors
    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)

    # Sort by eigenvalue (descending)
    sorted_idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[sorted_idx]
    eigenvectors = eigenvectors[:, sorted_idx]

    # Step 4: Project onto top n_components
    components = eigenvectors[:, :n_components]
    X_projected = X_centered @ components

    # Variance explained
    explained_variance_ratio = eigenvalues / eigenvalues.sum()

    return X_projected, explained_variance_ratio, components

# Example with the Iris dataset
from sklearn.datasets import load_iris

iris = load_iris()
X_iris = iris.data  # 4 features

X_pca, var_ratio, components = pca_from_scratch(X_iris, n_components=2)

print(f"Original shape: {X_iris.shape}")
print(f"Reduced shape:  {X_pca.shape}")
print(f"Variance explained by PC1: {var_ratio[0]:.3f}")
print(f"Variance explained by PC2: {var_ratio[1]:.3f}")
print(f"Total variance explained:  {var_ratio[:2].sum():.3f}")
```

### PCA with Scikit-Learn

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# Standard practice: scale before PCA
scaler = StandardScaler()
X_scaled = scaler.fit_transform(iris.data)

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

# Visualize
plt.figure(figsize=(8, 6))
scatter = plt.scatter(X_pca[:, 0], X_pca[:, 1], c=iris.target, cmap="viridis",
                      s=50, alpha=0.7, edgecolors="black", linewidths=0.5)
plt.xlabel(f"PC1 ({pca.explained_variance_ratio_[0]:.1%} variance)")
plt.ylabel(f"PC2 ({pca.explained_variance_ratio_[1]:.1%} variance)")
plt.title("Iris Dataset Projected onto 2 Principal Components")
plt.colorbar(scatter, label="Species")
plt.grid(True, alpha=0.3)
plt.show()
```

### How Many Components to Keep?

Plot the cumulative explained variance and choose the number of components that captures a sufficient fraction (often 90-95%):

```python
from sklearn.datasets import fetch_openml

# Use a higher-dimensional dataset
from sklearn.datasets import load_digits
digits = load_digits()
X_digits = StandardScaler().fit_transform(digits.data)
print(f"Original dimensions: {X_digits.shape[1]}")

# Fit PCA with all components
pca_full = PCA().fit(X_digits)

cumulative_var = np.cumsum(pca_full.explained_variance_ratio_)

plt.figure(figsize=(8, 5))
plt.plot(range(1, len(cumulative_var) + 1), cumulative_var, "o-", markersize=3)
plt.axhline(y=0.95, color="r", linestyle="--", label="95% threshold")
plt.xlabel("Number of Components")
plt.ylabel("Cumulative Explained Variance")
plt.title("PCA: Choosing the Number of Components")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Find number of components for 95% variance
n_95 = np.argmax(cumulative_var >= 0.95) + 1
print(f"Components needed for 95% variance: {n_95} (out of {X_digits.shape[1]})")
```

<KeyTakeaway>
PCA is not just a visualization tool. It is a practical preprocessing step that can speed up training and reduce overfitting by eliminating noisy, low-variance directions. When you reduce from 64 dimensions to 30 while keeping 95% of the variance, you are discarding noise while retaining the signal.
</KeyTakeaway>

## Combining PCA with Clustering

PCA and K-means complement each other powerfully:

```python
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score

# Load handwritten digits (64 features)
digits = load_digits()
X = StandardScaler().fit_transform(digits.data)
y_true = digits.target

# Reduce to 2D for visualization, more dimensions for clustering
pca_vis = PCA(n_components=2)
X_2d = pca_vis.fit_transform(X)

pca_cluster = PCA(n_components=30)
X_reduced = pca_cluster.fit_transform(X)

# Cluster in reduced space
kmeans = KMeans(n_clusters=10, n_init=20, random_state=42)
labels = kmeans.fit_predict(X_reduced)

# Evaluate against true labels (we happen to know them)
ari = adjusted_rand_score(y_true, labels)
sil = silhouette_score(X_reduced, labels)
print(f"Adjusted Rand Index: {ari:.3f}")
print(f"Silhouette Score:    {sil:.3f}")

# Visualize in 2D
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

axes[0].scatter(X_2d[:, 0], X_2d[:, 1], c=y_true, cmap="tab10", s=10, alpha=0.5)
axes[0].set_title("True Labels (colored by digit)")

axes[1].scatter(X_2d[:, 0], X_2d[:, 1], c=labels, cmap="tab10", s=10, alpha=0.5)
axes[1].set_title(f"K-Means Clusters (ARI={ari:.2f})")

for ax in axes:
    ax.set_xlabel("PC1")
    ax.set_ylabel("PC2")

plt.tight_layout()
plt.show()
```

## When to Use Unsupervised Learning

| Use Case | Technique | Example |
|----------|-----------|---------|
| **Customer segmentation** | K-means, GMM | Group users by behavior for targeted marketing |
| **Anomaly detection** | Isolation Forest, DBSCAN | Detect fraud, manufacturing defects |
| **Feature compression** | PCA | Reduce 1000 features to 50 before supervised learning |
| **Data visualization** | PCA, t-SNE, UMAP | Project high-dimensional data to 2D for exploration |
| **Preprocessing** | PCA | Remove multicollinearity, speed up training |
| **Topic modeling** | NMF, LDA | Discover themes in a collection of documents |

<WhyThisMatters>
In real-world ML projects, unsupervised learning is often the first step — even when you ultimately want to do supervised learning. You might use PCA to reduce dimensionality before training a classifier, or use clustering to create pseudo-labels for semi-supervised learning, or simply to explore and understand a new dataset before deciding how to model it.
</WhyThisMatters>

## A Complete Unsupervised Pipeline

```python
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import numpy as np
import matplotlib.pyplot as plt

# Step 1: Generate high-dimensional data with hidden clusters
X, y_true = make_blobs(
    n_samples=500, n_features=20, centers=5,
    cluster_std=2.0, random_state=42
)

# Step 2: Scale
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Step 3: Find optimal K using silhouette score
best_k = 2
best_score = -1
for k in range(2, 10):
    kmeans = KMeans(n_clusters=k, n_init=10, random_state=42)
    labels = kmeans.fit_predict(X_scaled)
    score = silhouette_score(X_scaled, labels)
    if score > best_score:
        best_k = k
        best_score = score
    print(f"K={k}: Silhouette = {score:.3f}")

print(f"\nBest K = {best_k} (Silhouette = {best_score:.3f})")

# Step 4: Cluster with optimal K
kmeans_final = KMeans(n_clusters=best_k, n_init=10, random_state=42)
cluster_labels = kmeans_final.fit_predict(X_scaled)

# Step 5: Reduce to 2D for visualization
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)

# Step 6: Visualize
fig, axes = plt.subplots(1, 2, figsize=(14, 5))
axes[0].scatter(X_2d[:, 0], X_2d[:, 1], c=y_true, cmap="tab10", s=20, alpha=0.7)
axes[0].set_title("True Labels")

axes[1].scatter(X_2d[:, 0], X_2d[:, 1], c=cluster_labels, cmap="tab10", s=20, alpha=0.7)
axes[1].set_title(f"K-Means (K={best_k})")

for ax in axes:
    ax.set_xlabel(f"PC1 ({pca.explained_variance_ratio_[0]:.1%})")
    ax.set_ylabel(f"PC2 ({pca.explained_variance_ratio_[1]:.1%})")
    ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

<CommonMistake>
Do not forget to scale your data before applying PCA. PCA finds the directions of maximum variance, so features with larger scales will dominate the principal components. StandardScaler ensures all features contribute equally. The exception is when the features are already on comparable scales (e.g., pixel intensities 0-255).
</CommonMistake>

## Summary

| Concept | Key Idea |
|---------|----------|
| **K-means** | Partition data into $K$ clusters by minimizing within-cluster distances |
| **Inertia** | $\sum \|\mathbf{x} - \boldsymbol{\mu}\|^2$, the K-means objective |
| **Elbow method** | Plot inertia vs. K, look for the "bend" |
| **Silhouette score** | Measures cluster cohesion vs. separation, range $[-1, 1]$ |
| **PCA** | Find orthogonal directions of maximum variance |
| **Eigenvalue** | Variance captured by each principal component |
| **Explained variance ratio** | Fraction of total variance in each component |
| **Scaling before PCA** | Essential — prevents large-scale features from dominating |
